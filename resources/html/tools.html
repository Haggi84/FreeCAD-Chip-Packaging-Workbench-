🔧 Tool Reference

Main Toolbar

Load GDSII

Purpose: Import a GDS layout file with color, technology, and 3-D options.

Input files: .gds (required), .lyp (required), .map (optional), stackup .xml (optional)

Import options:
  • Match KLayout — use exact LYP fill/frame colors
  • Highlight bondable — gold color for PIN/LEFPIN/PAD layers
  • Extrude to 3-D — polygon solids with PDK-accurate Z-heights
  • Contacts-only 3-D — full geometry for bond pads, single body box for rest
  • Auto PIN contacts — automatic contact-point markers on detected bond pads
Created objects: Layer_{name}_{id}, IC_Body_Solid, GDS_Pin_Instances, GDS_PINs_{layer}, ContactPoint_{n}

Move / Rotate Chip

Purpose: Translate and rotate all GDS chip objects as a group.

Scope: GDS Chip Objects / All Document Objects / Current Selection

Controls: Arrow buttons for XY, ▲▼ for Z; ±X/Y/Z rotation buttons around bounding-box center

Keyboard shortcuts (when dialog is focused):
←/→ = ±X    ↑/↓ = ±Y    PgUp/PgDn = ±Z
Shift + ←/→ = ±Rz    Shift + ↑/↓ = ±Rx    Shift + PgUp/PgDn = ±Ry

Restore Original — undoes all moves made in the current dialog session

Set Contact Points on Face

Purpose: Place contact point markers interactively on selected pad faces.

Phase 1: Ctrl+click faces in the 3-D view → click Generate Grid
Phase 2: Click grid points to select them → click OK

Result: contact_point_housing_{n} markers (yellow) placed at selected grid positions.
These housing-side contact points activate the Wire Bond command automatically.

Contact Point Browser

Purpose: Dock panel listing all contact points grouped by type.
Groups: Die-side (orange), Housing (yellow)
Interaction: Click a row to highlight the corresponding marker in the 3-D view.

Wire Bond

Purpose: Create 3-D solid bond wires between die pads and package leads.

Prerequisites: At least one die-side contact point (orange) and one housing contact point (yellow).

Workflow: Configure wire parameters → click die contact point → click housing contact point → wire is created

Wire geometry: Swept solid pipe with end caps — true solid, not a hollow shell.
Created objects: BondWire_{n}

Wire Bump Configurator

Purpose: Place parametric bump shapes at bond wire endpoints.

Shapes:
ShapeParametersTypical Use
Ball BondBall radius, neck radius, heightStandard thermosonic bonding
Wedge BondWidth, length, heightUltrasonic Al bonding
Stitch BondRadius, heightSecond bond in ball-wedge sequence
Nail HeadTop radius, base radius, heightHeavy wire bonds
Netlist browser: Shows all BondWire_* objects with net name, start/end CP, and wire length.
Check rows and click Place Bumps to place at both endpoints.
Created objects: WireBump_{shape}_{n}

Define Port

Purpose: Draw simulation ports on the layout — rectangles with no volume, standing on an edge.

Three clicks: click an edge where the port starts; click again along it to set the length; move the mouse up or down and click to set the height and the direction (+Z / −Z).
It then starts the next port and keeps going. Esc abandons the port being drawn, Esc again or Finish ends the session.

A height typed into the panel is used instead of the cursor's, so the third click only picks the direction. The panel also carries the reference impedance.

Created objects: Port_{n} in a Ports group inside GDS_Die. They are parametric — length, direction and height stay editable — they move with the chip, and they are ignored by the design rule check and the thermal export.

Import KiCad

Purpose: Bring a KiCad board's components, pads and nets into the assembly.

Input files: .kicad_pcb (required), .net (optional — the board is checked against it and any disagreement reported before anything is built)

Bodies: the footprint's STEP model where it can be found (KiCad's ${KICAD*_3DMODEL_DIR} is honoured, and a folder can be given), otherwise a stand-in body the size of the courtyard.
Pads: ordinary contact points carrying PadName (R1.2), ComponentRef and NetName, placed on the plane the components stand on.

KiCad's Y axis points down the page and FreeCAD's points up, so positions are mirrored and rotations negated on the way in.

Nets / Update Ratsnest

Purpose: Show what is still to route.

A rubber line is drawn for every connection a net still needs — pads already joined count as one, so n groups need n−1 lines. Route a connection and its line disappears by itself; move a component and the lines follow.

The Nets panel lists each net with its pads, open connections and routed ones; clicking a row selects that net. Update Ratsnest redraws on demand.

Stack Die

Purpose: Put one die on another, with the die attach between them.

Sets the height from the base die's top plus the adhesive thickness, optionally centres the die, builds the die attach as real material (assigned Die attach epoxy), and records the tier.
The die's pads move with it — including the positions they store, which is what bonding and the design rules read.

Reports: how much of the upper die hangs over nothing, and which pads of the die below it now covers.

Dies

Purpose: List the dies of the assembly: name, tier, what each sits on, size, thickness, pads and how many are bonded.

Isolate shows only the selected die and its pads — in a stack the 3-D view otherwise shows mostly the top die. Refresh finds dies added since, naming and tiering any new one.

Detect Package Pads

Purpose: Place contact points on the bond fingers of an imported package model.

Usage: Select the package body, then run the command. It lists the planes of near-horizontal faces with their face count, size range and how much of each lies around the outline; pick the plane holding the ring of like-sized faces.
Faces between 0.01 mm² and 150 mm² are considered, so the package body itself stays out of the list. Faces that already have a contact point are skipped.

Created objects: contact_point_housing_{n}

Propose Netlist

Purpose: Write a first pinout when none exists yet.

Sorts die pads and package pins by angle and pairs them in ring order — each pad to the pin facing it, with no crossings — then writes a netlist CSV (counts, unpaired points and crossing count as comments) and offers to bond it immediately.
Die-side means lying over a chip proxy or die body. A document without a die is refused rather than paired arbitrarily.

The proposal is a starting point: edit it for supply pins and anything the pad order dictates.

Import Netlist

Purpose: Bond every connection listed in a CSV netlist.

Format: header net,from,to (or die_pad / package_pin), one connection per row; # lines are ignored.
Matching: contact point name, pad name from the layout's label, label, lead pin number, lead name — case-insensitive.
Ambiguous or unknown ends are listed, never guessed. Re-importing renames existing wires instead of duplicating them.

Export Bonding Diagram

Purpose: Write <name>_bonding_diagram.svg (plan view, wires numbered) and <name>_wire_table.csv (net, pads, span, length along the loop, loop height, diameter).

Purpose: Check routed traces and bond wires in the active document.

Rules:

Interaction: Click a finding to select the offending objects.

Assign Materials

Purpose: Tag every solid with its material for simulation export.

Sources: die body from the stackup; leads and paddle from the Leadframe Configurator; housing and lid from the Housing Configurator; bond wires and bumps gold; traces copper; chip proxies silicon; BGA balls SAC305.

Parts it cannot decide — GDS interconnect layers, imported STEP models — are listed and set to Unassigned. Pick a material in the property editor under Material ▸ PackageMaterial; that choice is kept when the command runs again.

Export for Thermal Simulation

Purpose: Write the assembly for a thermal solver.

Output: <name>_<material>.step per material, <name>.geo (Gmsh script with one physical volume per material), <name>_materials.csv, <name>_manifest.json

Meshing: gmsh <name>.geo -3 — geometry is converted to metres, parts share nodes across interfaces.
Overlaps: mould compound and housing are cut by the parts inside them; overlaps between other materials are reported, not changed.
Boundary conditions: die power, heat-sink temperature (underside), convection coefficient and ambient temperature — named as surfaces in the Gmsh script, values in the manifest.

Session ▾

Save Design Session: Saves the active document as a native FreeCAD .FCStd file — the exact current design state, including manual edits, not a replay of recognized actions.
Load Design Session: Opens a previously saved .FCStd file.

Both are thin wrappers around FreeCAD's native save/open — Ctrl+S and File → Open work identically. A few workbench-only display settings (VIA detail mode, lazy GDS layer-loading state) are captured and restored automatically alongside the document.

Advanced Tools ⇄

Purpose: Toggle the visibility of the Advanced Tools toolbar.
The advanced toolbar is hidden by default to keep the main toolbar uncluttered.

Advanced Toolbar

Leadframe Configurator

Purpose: Generate a parametric semiconductor package leadframe.

Package types: QFN (Quad Flat No-lead), QFP (Quad Flat Package), BGA (Ball Grid Array)

Parameters: Frame size (L×W×T), lead count per side, lead pitch, lead width/length, die-attach paddle size, material

Leadframe Library (STEP Import)

Purpose: Import a real STEP package model from the IHP mirror-semi online library.

Workflow: Browse library → select package → confirm orientation face → confirm die-attach face → STEP model is placed at the correct position in the GDS document

Housing Configurator

Purpose: Generate a transparent IC package housing around the leadframe.

Parameters: Wall thickness, clearance, housing height, lid (yes/no), transparency, alignment posts, material

Layer on Leadframe

Purpose: Import GDS layers and stack them directly onto an existing leadframe.

Features: Auto-scale to fit die-attach paddle, rotation, mirror, Z-offset, combined GDS + leadframe in one document

Define Contact Points

Purpose: Batch-place contact point markers at the top-face centre of selected GDS layer objects.

Usage: Select one or more Layer_* objects in the 3-D view, then click this button.
Each selected object gets one ContactPoint_{n} marker at its highest Z face centre.
